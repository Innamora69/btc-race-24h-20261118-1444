A capped dip-buy bot for Coinbase Wrapped BTC (cbBTC) on 1-minute on-chain prices. It buys at least 2% below the highest close of the last 240 bars, takes profit at +1.5% over cost or stops out at -1% under it, and never trades more than 2 round trips per 24-hour window. Dev grade on the frozen dev window: +$13.41 net PnL, 2 trades, 0.64% maximum drawdown.

## Run it

```sh
python3 -P -s main.py
```
